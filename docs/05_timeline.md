# Хронология

Этот файл используется для контроля возраста героев и последовательности событий.

Календарные годы рабочие. При изменении нужно сдвигать всю шкалу целиком.

## До рождения Ильи

| Когда | Событие |
|---|---|
| 2041 | Учёные Земли открывают портал. Первая экспедиция называет иной мир Эдемом. |
| 2041–2043 | Исследования, экспедиции, первые базы у арки Врат. Глеб Ракитин и Андрей Северин служат в охране первой экспедиции. |
| Весна 2043 | **День Разлома.** Красный и Синий Владыки в битве за границу расширяют портал и прорываются на Землю. С ними идут меньшие существа. |
| Весна 2043 | Месячная война на Земле. Ядерные удары не убивают кайдзю. |
| Апрель 2043 | Красный Владыка взрывается при перегрузке и уничтожает себя и Синего. |
| 2043 | На Земле начинается локальное терраформирование. |
| Лето 2043 | Начало экспериментов с сыворотками на тканях кайдзю и существ. |
| Осень 2043 | Андрей Северин получает красную сыворотку и выживает. Глеб не проходит тест совместимости. |
| Зима 2043–2044 | Андрей на Земле для демонстрации результатов. Зачатие Ильи. |
| Весна 2044 | В Эдеме рождается Юна Хан — одна из первых детей, родившихся в ином мире. |
