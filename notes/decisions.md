## Болезни и адаптация

| Вопрос | Решение |
|---|---|
| Одна болезнь или несколько | Комплекс — адаптационный синдром Эдема, «эдемка». |
| Главный фактор | Фоновый резонанс будит «Ось», взрослый иммунитет атакует перестройку, сверху ложатся местные микробы. |
| Почему молодые выживают | «Ось» у них перестраивается быстрее иммунного ответа. |
| Естественная адаптация | Возможна. Рождённые в Эдеме почти не болеют (Юна Хан). |

Подробно — [06_energy_and_biology.md](../docs/06_energy_and_biology.md).

## Энергия

| Вопрос | Решение |
|---|---|
| Что это физически | **Резонанс** — энергия, запасённая в резонансных узлах. |
| Измерение | Индекс резонанса (ИР), прибор — резонометр. |
| Почему красное взрывается | Положительная обратная связь, лавинообразный разгон. |
| Почему синее каменеет | Отрицательная обратная связь, излишек связывается в кристалл. |
| Обратимость | Малые отложения частично обратимы, крупные — нет. |
| Другие типы | Да, третий тип — во второй книге. |

## Программа

| Вопрос | Решение |
|---|---|
| Возраст | 15–21, исключения для военных. |
| Кто может записаться | Любой гражданин Протектората подходящего возраста. |
| Разрешение опекуна | Да; за сирот — директор учреждения. |
| Отбор | Медицина, физика, собеседование, тест совместимости. |
| Что значит 50% | 50% рабочая модификация, 30–35% смерть, 15–20% «пустые». |
| Рейтинг | Официальный **Реестр** на 50 мест, обновляется ежемесячно. |
| Место в армии | Отдельный род войск — Корпус Резонанса. |
