# Новый Эдем: За гранью мира

Научно-фантастическая постапокалиптическая история о человечестве, которое после катастрофы на Земле вынуждено переселиться в иной мир.

## Ключевая идея

После открытия портала в иной мир на Землю прорываются два гигантских существа — красное и синее. Их месячная битва, появление меньших монстров, применение ядерного оружия и распространение чужеродной энергии меняют Землю и запускают локальное терраформирование.

Человечество начинает осваивать иной мир и экспериментировать с красной и синей энергией местных существ, пытаясь адаптировать людей к новой среде.

Главный герой — сын одного из первых красных суперсолдат. После окончательного переселения он теряет мать, попадает в приют и позже узнаёт о новом наборе в программу модифицированных бойцов.
